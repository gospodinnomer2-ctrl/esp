1. Создай на github.com новый репозиторий.
2. Загрузи в него ВСЁ содержимое этой папки (включая папку .github).
3. Открой вкладку Actions -> build -> когда станет зелёным, внизу в Artifacts скачай esp-mod.
4. Распакуй zip, положи .jar в .minecraft/mods (нужны Fabric Loader и Fabric API для 1.21.4).
5. В игре: клавиша 0 открывает меню.
